# Kurikulum Codeventure

60 pelajaran berurutan: HTML 15, CSS 15, JavaScript 18, Laravel 12. Setiap pelajaran memuat penjelasan, contoh, tugas, kuis, dan rujukan primer. Semua 48 pelajaran frontend memiliki latihan dengan pemeriksaan dan petunjuk. PHP/Laravel dipraktikkan di proyek lokal terpisah. ID pelajaran lama tetap berlaku.

## Catatan praktik

Editor HTML/CSS tidak memuat sumber eksternal atau mengeksekusi script. Contoh yang memerlukan gambar, metadata dokumen lengkap, atau pengiriman formulir juga memiliki langkah pengujian lokal. JavaScript berjalan dalam worker dengan console dan batas 1,5 detik; praktik DOM/storage menggunakan fungsi terpisah pada runner dan contoh lengkap untuk file lokal. Pemeriksaan keluaran membantu latihan, bukan pembuktian seluruh kemungkinan masukan.

55 URL rujukan unik diperiksa dan merespons HTTP 200 pada 28 Oktober 2026.
